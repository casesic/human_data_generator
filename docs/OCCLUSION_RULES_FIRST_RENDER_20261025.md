“有效遮挡”按当前 MAMMA reader 的 `visibility_loss_valid` 与 `visibility=0` 的交集计算，并不是只看原始 NPZ 中的 0。455 条 observed 的原始点值为 49,031 个 1、29,227 个 0、154,702 个 -1；其中 183 个原始 0 没有进入实际遮挡损失。另有 190,113 个有效坐标点，`visibility=-1` 不自动取消可靠坐标监督。245 条样本同时有有效 0/1，208 条只有有效可见点，2 条没有 visibility 监督且没有可更新坐标监督。89 条 absent 中 88 条为 `empty_target_mask`，1 条为 `degenerate_target_mask_box`，均留在观察清单内。

三个规则都在不同人物、相机和时刻产生了人与人遮挡，而不是只在一个孤立帧出现。双人直行的 p1/p2 分别有 23/16 条含有效 0，时间覆盖 frame 0–13 / 8–15；双人斜交的 p1/p2 为 42/45 条，四路 rig/camera 都有；三人直行的 p1/p2/p3 为 48/48/23 条，p1 和 p2 覆盖 24 个时刻，p3 覆盖 18 个时刻。这里的连续帧是同一场景的相关观察，不能当作相同数量的独立遮挡类型。

叠加页中，双人直行 frame 7/rig_side/cam2 的后方 p1 上身与右侧被 p2 挡住；frame 15/cam4 则是 p2 被 p1 遮挡，但所剩 mask 仅约 47×230 像素。双人斜交 frame 8/rig_custom_1/cam2 的 p2 面部、躯干及腿部被 p1 遮挡；frame 22/cam4 的 p1 大部分躯干被 p2 挡住。三人直行 frame 0/rig_side 的 p1、p2 分别被近处 p3 遮挡；rig_custom_1/cam4 的 p3 被 p2 遮挡。frame 16/rig_side/cam2 的 p1 只剩约 74×210 像素的 mask，是很强的遮挡例。三人场景的近处 p3 在首帧 cam2 约高 1,887 像素，尺度明显偏大；部分画面还有物理有效域的黑色边缘和人物几何相互穿插。它们没有被隐藏或修饰，应在后续选数据时由用户判断是否符合想要的分布。

对所有 29,227 个原始 0，核对了保存的前景实例、深度差、3×3 邻域一致性和证据完整标记：本批均是 `occluded_by_other_person`，没有把未知点改为 0。抽看上述八条画面及其 mask/点叠加，前景实例与目标不同，红点位置和人物遮挡关系相符；这只是代表性目视检查，**不是全批逐点人工认证**。人体自身背面点仍有大量 -1，本批没有解决自遮挡标签资格问题。

## 执行与检查

双人直行的首次 CPU 准备被旧的 700 万像素 ROI 上限拒绝，但该 ROI 位于真实 ERP 内；移除这条任意面积上限后，同一 v0001 在 `straight2_retry1` 准备和渲染成功。三人直行的首次 CPU 准备被过度保守的方形 ROI 包络判成图像外；规划现将纵向 ROI 限制在实际 ERP 内，**实际 mask 的 1.2 扩张、384:512 裁剪及滤波支持仍由消费者严格检查**。同一 v0001 在 `straight3_retry1` 完成全部帧，首帧真实目标也通过了该检查。两个准备失败目录保留，均未产生相机调用。启动时受默认沙箱的 NVIDIA 驱动访问限制，改用本次授权的 GPU 执行边界；该预检失败也没有相机调用。没有真实渲染重试，计划与实际均为 224 次。

双人斜交使用 GPU0 `GPU-d481acc7-106f-29e5-1298-8c0d398261b2`，任务用时 605 秒；双人直行与三人直行依次使用 GPU1 `GPU-6f046d56-acbe-d49b-774a-9d463e768cac`，分别用时 376 和 926 秒。每包 `status.json` 都是 `data_complete`，Blender/consumer 正常退出，任务自有临时缓冲为 0。核对 `events.jsonl` 的有序相机调用、全部帧/rig/camera/person 观察格和实际文件；MAMMA `MammaSavedGTDataset` 完整检查三包标签和 mask 支持，并为每个人实读一条 RGB/mask（共 7 条）。未构造模型、前向、训练或修改现有 16/4 划分、四套模型及真实评审数据。

这三个 v0001 都**值得作为后续扩批候选**：按当前标签和 reader，已有明确的有效人与人遮挡监督，不必为得到 0 而先收窄规则。旧城市训练集的对应比例是 126/1,628（7.7%）；这里只是三个有意设计遮挡的样本，不能把 53.8% 与旧集当作同分布效果对照。三人场景的强遮挡、大尺度和人物穿插值得用户先看原图；单个变体不能保证规则中的其他扰动同样产生这些数量或质量。后续是否扩批、是否把新包加入训练以及如何划分，留待单独决定。
